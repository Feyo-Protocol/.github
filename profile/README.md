# Feyo Protocol

**Building open payment infrastructure on Stellar.**

Feyo is an independent, open-source fintech project focused on making stablecoin payments easier to integrate, authorize, and verify.

We're building financial infrastructure for applications, developers, and AI agents—with transparency, security, and user-controlled wallets at the core.

### What we're building

Our current Stellar Testnet application supports:

- Varial/Freighter wallet connections
- Read-only account balances
- Validated payment drafts
- Transaction lifecycle UI
- Open-source documentation and automated testing

We're working toward wallet-authorized payments, independently verified settlement, developer APIs, AI-agent integrations, and regulated payout infrastructure.
